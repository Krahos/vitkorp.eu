PlanTer, short for Planning Terminal, is a project management application
written in Rust, with a desktop interface built with
[iced](https://iced.rs). The domain logic lives in a separate crate,
[planter-core](https://github.com/Krahos/planter-core). It is in early
development and licensed under AGPL-3.0. More details will come soon.
